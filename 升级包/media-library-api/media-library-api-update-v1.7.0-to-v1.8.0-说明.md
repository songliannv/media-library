# media-library-api v1.7.0 → v1.8.0 升级说明

发布日期：2026-09-23

---

## 这次改了什么

**一句话：后台不再"自己控制自己"。** 登录后台改用**账号 + 密码**；令牌只属于外部调用者。

### 1. 之前的毛病（你指出的）

| 原来 | 问题 |
|---|---|
| 安装时装完弹一个「后台管理令牌」 | ❌ **自己给自己发密钥**，毫无意义 |
| 进后台要先在顶部输入框填那个令牌 | ❌ 自己的站点，还要自己给自己设关卡 |
| 令牌存在浏览器 localStorage | ❌ 换台电脑就得重新填；忘了就进不去 |
| `admin.token` 还同时兼职外部调用密钥 | ❌ 两件事混在一起（v1.7.0 已拆开） |

### 2. 现在怎么做

**装站时创建一个管理员账号**（就是你自己）：

```
安装向导 第 2 步：
  数据库地址 / 端口 / 库名 / 用户名 / 密码
  管理员账号  ← 你以后登录后台用的账号
  管理员密码  ← 至少 6 位
  站点名称 / 站点网址
```

**登录后台**：打开 `/admin` → 输入账号 + 密码 → 进入。会话保持，不用每次填。

**外部调用者的 API 令牌**：进后台 →「**API 调用**」页逐个创建（这是 v1.7.0 加的，本版保留）。
每个令牌仍可单独设每日限额、IP 白名单，并记调用流水。

**管理员是谁**：安装时创建的那个账号（`app_users` 表里 `email` 标为 `ml-admin@local`）。
将来有多个管理员时，认的是这个标记，不依赖 id 顺序。

### 3. 后台各页的连带调整

| 位置 | 变化 |
|---|---|
| 后台顶部 | 「管理 Token」输入框 → 改为「当前登录：xxx / 退出登录」 |
| 系统设置 | 去掉「后台管理令牌」这一项（其余 TMDB/RAWG Key、数据源、网盘类型不变） |
| 安全防护 | 顶部说明改为「登录已改为账号 + 密码」 |
| check.php | 门槛从「带令牌」改为「管理员登录态」（或从服务器本机访问） |
| config.php | 不再生成 `admin.token`，只留 `admin.dir` / `show_link` / `show_icon` |
| 安装信息备忘 | 记录管理员**账号**（不记密码） |

## ⚠️ 升级前必读（重要）

**你原来的管理员账号怎么来？**

本版起后台认「管理员账号」。升级到 v1.8.0 后：

- **A. 你已经有一个能登录的账号** → 直接用它登录后台即可。（本站前台注册用户表 `app_users` 里 id 最小的那个会被认作管理员；安装时创建的那个也会被标 `ml-admin@local`。）
- **B. 你从没建过前台账号** → 升级后 `/admin` 会要求登录，而你没有账号。
  **解决办法（任选其一）**：
  1. **重装**：删掉 `config/install.lock` 与 `config/config.php`，重新打开 `/install.php`，填好数据库（**库名/用户名/密码要与原来一致**，数据不会丢），并创建管理员账号；
  2. **手工建一个**：在数据库里执行（密码换成你自己的）：
     ```sql
     INSERT INTO app_users (username, email, pass_hash, status, created_at)
     VALUES ('admin', 'ml-admin@local', '<bcrypt散列>', 1, NOW());
     ```
     散列值可在服务器终端生成：
     ```
     php -r "echo password_hash('你的密码', PASSWORD_DEFAULT);"
     ```
  3. **临时放行**：从服务器本机（宝塔终端）访问 `curl http://127.0.0.1/check.php` 仍可用。

  > 推荐用 1 或 2。做完后用 `/admin` 登录，能看到「API 调用」菜单就正常了。

## 升级步骤

1. **备份**数据库 + 站点目录。
2. 用升级包里的文件**覆盖**站点对应位置（目录结构不变）。
3. **数据库不用手工动** —— 表结构没变，只是代码不再读写 `app_settings.admin_token`。
   （旧库里残留的 `admin_token` 记录留着无害，不会再生效。）
4. `Ctrl+F5` 刷后台 → 出现**登录页**即升级成功 → 用管理员账号登录。
5. 若没有可用的管理员账号，按上面「⚠️ 升级前必读」处理。

## 不需要做的事

- ❌ 不用改 Nginx 伪静态
- ❌ 不用动计划任务
- ❌ 外部调用者**不受影响** —— `/api/v1/*` 仍是公开的，带不带 API 令牌都能调

## 回滚方法

把上面 13 个文件换回 v1.7.0 的版本。注意回滚后后台又变回「填令牌」，而 `config.php` 里已没有 `admin.token`，
需要手工补一段 `'admin' => ['token' => '你的令牌', ...]` 才能进后台。
