# media-library-api v1.6.5 → v1.7.0 升级说明

发布日期：2026-09-23

---

## 这次改了什么

**一句话：前后台令牌彻底分开 —— 后台登录令牌只给站长自己用，外部 API 调用者各自发独立令牌。**

### 1. 之前的毛病

系统原来只有**一个全局令牌**（`config.php` 里的 `admin.token`），它同时干了两件不相干的事：

| 原来 | 问题 |
|---|---|
| 站长登录后台用它 | 合情合理 |
| 外部系统调 `/api/v1/*` 也用它 | ❌ 所有人共用一个密钥，谁调的、调了多少，完全看不出来 |

再加上 `/api/v1/*` 是**完全公开**的，没令牌也能随便调 —— 想限制调用量、想查调用明细，都做不到。

### 2. 现在怎么做的

**新增「API 调用令牌」体系（后台新增一级菜单：API 调用）**

- 站长在后台给**每个调用者**发一个独立令牌，填个名称（如「客户A」「某某App」）
- 每个令牌可单独设置：
  - **每日调用上限**（0 = 不限），超出即拒绝
  - **IP 白名单**（逗号分隔，留空 = 不限）
  - **启用 / 禁用**开关
- 每次调用都记流水：**谁、什么时候、调了哪个接口、什么参数、来自哪个 IP、耗时多少**
- 令牌可随时删除，删掉立刻失效（其调用记录一并清除）

**调用方式**（两种，任选）：

```
请求头：  X-Api-Token: <令牌>
URL：     /api/v1/search?q=庆余年&token=<令牌>
```

**兼容性**：`/api/v1/*` 仍然是公开的 —— **不带令牌也能调**，只是不记用量、不受限额约束。
即：老调用方**不用改任何代码**，改造是渐进式的。

### 3. 后台登录令牌（admin.token）保持不变

仍然是 `config.php` 里那一个，仍然只在「系统设置」里改。
它现在**只服务于站长登录后台**，与外部调用者彻底解耦。

## 变化文件（5 个）

| 文件 | 变化 |
|---|---|
| `core/ApiToken.php` | **新增**。令牌校验、用量记录、限额与 IP 白名单、后台接口 |
| `api/unified.php` | 公开接口支持 `X-Api-Token` / `?token=` 校验并记流水；新增 5 个后台管理接口 |
| `admin/index.php` | 新增「API 调用」一级 Tab：令牌列表 / 新建 / 编辑 / 删除 / 调用记录 |
| `sql/install.sql` | 追加 `app_api_tokens`、`app_api_logs` 两张表（手动装站用） |
| `index.php` | 版本号 1.6.5 → 1.7.0 |

---

## 升级步骤

1. **备份**（数据库 + 站点目录），老规矩。
2. 用升级包里的文件**覆盖**站点对应位置：
   ```
   core/ApiToken.php       ← 新增文件
   api/unified.php         ← 覆盖
   admin/index.php         ← 覆盖
   index.php               ← 覆盖（仅版本号）
   ```
3. **数据库不用手工建表** —— 首次打开后台「API 调用」页时程序会**自动创建** `app_api_tokens` 与 `app_api_logs` 两张表。
   （若你想手工建：`sql/install.sql` 末尾已给出这两张表的 DDL。）
4. 清一下浏览器缓存（`Ctrl+F5`），打开后台 → 看到新的「**API 调用**」菜单即升级成功。
5. 点「+ 新建令牌」给第一个调用者发令牌，把令牌和调用方式发给他。

## 升级后自查

| 检查项 | 预期 |
|---|---|
| 后台出现「API 调用」菜单 | ✅ |
| 点进去能看到「令牌总数 / 今日调用 / 累计调用」数字 | ✅ |
| 新建一个令牌后，列表里能看到它 | ✅ |
| 用该令牌调 `/api/v1/items?token=xxx` | 返回数据，且「调用记录」里出现一条 |
| 不带令牌调 `/api/v1/items` | 仍然返回数据（公开接口不变） |

## 不需要做的事

- ❌ 不用动 `config.php`
- ❌ 不用改 Nginx 伪静态（接口路径没变）
- ❌ 不用改计划任务
- ❌ 老调用方**不用改代码**（公开接口依然可用）

## 回滚方法

把上面 5 个文件换回 v1.6.5 的版本即可，数据库里多出的两张表留着不影响运行。

## 小提示

- **令牌只在创建时完整显示一次**，请当场复制保存。列表里只显示前 12 位。
- 建议一个调用者一个令牌，不要多人共用一个 —— 否则出问题时无法定位是谁。
- 如果你想让 API **必须带令牌**才能调用（完全关闭公开访问），告诉我，可以加一个开关。
