🛠 安装向导

媒资资料库 · 网页安装向导

跟着下面三步走：环境自检 → 填数据库信息 → 点一下安装。装完后本页面会自动失效。

1环境自检

不通过的项目会标红，按提示处理后刷新本页即可。
PHP 版本 ≥ 5.6当前 7.4.33（fpm-fcgi）
扩展 pdo_mysql数据库访问必需
扩展 curl采集上游数据必需
扩展 json接口与配置读写必需
扩展 mbstring已启用（中文标题截断更准确）
扩展 openssl已启用（令牌随机性更好）
config/ 目录可写可写（安装器要在这里生成 config.php 与 install.lock）
站点根目录可写不可写（安装仍可完成；只是 uisc/ 需手动创建）
→ 宝塔 → 网站目录权限给 www 属主；或手动创建 uisc/ 目录
uisc/ 静态页目录已就绪（内页静态化输出目录）

2数据库信息

先把库建好：宝塔 → 数据库 → 添加数据库；这里填的账号密码要和它一致。
宝塔本机就填 127.0.0.1；独立数据库服务器填它的 IP
默认 3306
如果是 MySQL 8 + PHP 5.6，请在宝塔里把该用户密码改成 mysql_native_password 认证

3站点与密钥

这些装完也能在后台改，现在填好可以少跑一趟。
用于 canonical / robots.txt / sitemap.xml，结尾不要带 /
后台登录用；至少 6 位。点这里生成一个
安装会：建 6 张表 → 生成 config/config.php → 写 config/install.lock 锁死本页面
🔒 关于安全：网页安装器 install.php 是带自锁的，不是常驻入口。本页面只在「尚未安装」时可用 —— 一旦写入 config/install.lock（或手填的 config/config.php 里数据库信息已生效）， 它立刻对所有访问者返回 404，没人能借此重装站点。 想用终端安装也行：php tools/install-cli.php（两份入口共用同一套安装内核）。
