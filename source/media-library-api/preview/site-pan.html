夸克网盘 · 默认转存目录

转存后的存放目录，例：/资源/电影。留空表示网盘根目录。

夸克网盘 · 临时资源目录

转存过程中的中转目录，处理完可清理。留空表示与默认转存目录相同。

键名规则：每种网盘三个键 —— pan_<代号>_cookie / pan_<代号>_dir / pan_<代号>_tmp，由 core/Settings.php 的 panAccounts() + panMap() + schema() 循环生成，表单与页签自动出现。
新增一种网盘：只在 panAccounts() 里加一行「代号 => 中文名」，后台表单、页签、自检项会自动跟上，不用改模板。
存储：Cookie 是长文本，用 textarea 保存进 app_settings；后台不会把它回显到前台任何页面。
