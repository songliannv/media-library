================================================================
  媒资资料库（media-library-api）· 功能说明
  版本：v2.2.0          更新：2026-09-24
================================================================

【一句话介绍】
  一套自己搭的「影视 / 游戏 / 动漫」资料库：后台自动采集热门条目 →
  前台卡片墙展示 → 可下载、可筛选、能被搜索引擎收录；
  同时对外提供标准 API，可直接对接 ZBLOK 等 WordPress 资源主题。


【v2.2.0 新增 · 三合一增强】
  ① 修：演员阵容不显示
     v2.1.1 起 Tmdb::normalize 已从 credits 抽取演员到 extra.cast，
     但 Views::castBlock 读的是 payload.credits.cast —— 两条路径不通，
     前台永远看不到演员。v2.2.0 改成优先读 extra.cast，保留 payload 兜底。
     升级后需要后台点一次「生成静态页」，让已生成的 /uisc/*.html 内页刷新一遍。

  ② 新增：每小时自动采集可配置
     后台「同步采集」页新增两个开关：
       · 每小时自动采集（开/关）—— 关闭后 cron 计划任务会跳过
       · 每小时采集条数（默认 5，1~50）—— 仅作用于计划任务，
         不影响后台「立即同步」用的「每源条数」
     宝塔计划任务照旧每小时跑一次 cron/sync_hourly.php，
     现在会根据后台配置自动决定采不采、采多少条。

  ③ 新增：标签详情路由 /tag/{slug}
     详情页里的标签胶囊改为可点击链接，点进去列出该标签绑定的全部条目（跨源）。
     例如 /tag/剧情、/tag/%E7%9F%AD%E5%89%A7、/tag/Sci-Fi%20%26%20Fantasy。
     与首页「?tag=xxx」共用同一套查询，只是 URL 永久、易 SEO。


【v2.1.3 新增 · TMDB ⇋ 短剧聚合 跨源联动】
  短剧侧本身没 rating/vote_count，TMDB 侧没 play_count/episodes —— 正好互补。
  新增 Core\CrossLink 模块，按标题三级匹配（exact=3 / start=2 / contain=1）双向补齐：
    ① 短剧 → TMDB：用短剧标题实时查 TMDB，取回 rating/vote_count/genres/overview/poster
                  只填空字段（rating、vote_count、overview、poster），genres 取并集去重
                  匹配到的 TMDB 条目完整元信息写进 extra.tmdb_links
    ② TMDB → 短剧：用 TMDB 标题在本地库搜短剧（不走上游，避免限流）
                  只把短剧的 play_count/episodes/duration/record_number 挂到 extra
                  不改 TMDB 主字段（rating/vote_count 保持 TMDB 权威数据）
    匹配规则：
      - 标题归一化：去空格 / 中英文标点 / 小写 + 简化版繁→简
      - min_rating=6.0（避免垃圾匹配，可配置）
      - MIN_LEN=4（短方 ≥ 4 字符才参与 contain/start 匹配，避免"妈妈"过度匹配）
  触发时机：
    - 同步后自动跑（`sync.enable` 且 `crosslink.auto_after_sync`）
    - 后台手动：POST /api/v1/admin/crosslink/run（支持 ids/limit/force）
    - 查看配置：GET  /api/v1/admin/crosslink/cfg（含最近 30 条联动明细）
  配置项（config.php `crosslink` 段，全部可选）：
    'crosslink' => [
        'enable'          => 1,       // 总开关
        'auto_after_sync' => 1,       // 同步后自动跑
        'batch_size'      => 20,      // 单次最多处理
        'min_rating'      => 6.0,     // TMDB 侧最小评分门槛
        'match_level'     => 3,       // 最大匹配级别 1..3
        'dry_run'         => 0,       // 1 = 演练不写库
    ],

【v2.1.2 修复 · 短剧聚合适配器重写】
  老版本用 `?act=recommend/search/new/detail` 参数，上游 orz.icicic.icu 根本不认，
  每个请求都直接超时——同步跑 0 条是真实的，不是缓存问题。
  全部换成官方参数：
    type=days_7_to_date&action=today_new|mj_today_new|aiju_today_new&page=N  今日上新（综合/蜜橘/爱剧）
    type=rank&selected_items=ranklist_hot_sc|ranklist_hot_all_sc|ranklist_hot_xz  排行榜
    type=search&name=关键词&page=N&page_size=20                                    搜索
    type=bookid&book_id=ID                                                        分集
  关键改动：
    - rank 嵌套解析：上游返回 {cell_data:[{video_data:[…]}]}，新增 flattenCells() 抽平
    - duration 双形态：兼容 `"1小时28分钟"` 字符串 与 `8285` 秒数
    - 分类白名单 + 中文兜底：60+ 主流分类，isKnownGenre 用 `^[\x{4e00}-\x{9fa5}]{2,4}$` 过滤上游乱码
    - source_id 三级兜底：book_id → vid → series_id
    - detail 语义改正：`type=bookid` 上游返回的是分集列表（不是书籍元数据），
      因此 detail 只填 extra.episodes，不覆盖其它字段

一、前台（访客看到的部分）
----------------------------------------------------------------
  1) 主页  /
     · 卡片墙：海报 / 标题 / 评分 / 年份 / 类型
     · 排序切换：热度 / 点击 / 最新 / 评分
     · 分类筛选：短剧 / 电影 / 电视剧 / 动漫 / 综艺 / 游戏
     · 分页浏览；可选「最新更新」区块
     · 前台不出现「API」等字样，访客看到的就是一个正常资源站

  2) 静态内页  /uisc/{id}.html
     · 详情信息 + 按类型差异化展示
       （影视→演职人员、游戏→平台厂商、动漫→话数制作公司、人物→生平）
     · 多条网盘下载：夸克 / 迅雷 / 光鸭 / 百度 / UC（后台可自由增删类型）
     · 只有填了下载地址才显示下载区
     · 真实静态 HTML，收录友好

  3) 注册 / 登录 / 退出  【v1.6.2 新增】
     · /user/register 注册：用户名 2~20 位（支持中文）/ 邮箱选填 /

     · /user/login 登录、/user/logout 退出

  4) 资源请求  /request  【v1.6.2 新增】
     · 注册用户填写想找的资源：片名 / 类型 / 年份 / 备注 / 联系方式

  5) 顶部导航与顶栏
     · 导航项后台勾选（主页 / 榜单 / 分类 / 资源请求 / 自定义外链）
     · 右上角用户区：未登录显示「登录 / 注册」，登录后显示

     · 资源请求：13 项开关（开放注册 / 必须登录才能提交 / 注册审核 /
       图形验证 / 游客可看 / 公开列表 / 显示联系方式 / 导航入口 /
       每日上限 / 最少标题字数 / 页面标题 / 页面简介 / 站长公告）

  4) 资源请求  【v1.6.2 新增，一级页签】

       重复条目自动跳过；只为新条目生成静态页

       ⑨ 采集与计划任务 ⑩ 站点设置·SEO·网盘接口 ⑪ 注册与资源请求
     · 支持 ?format=json 供程序读取；未登录管理员且非本机访问一律 404

    后台可一键全量重建。
  · /robots.txt 与 /sitemap.xml 由路由动态输出，内容在后台 SEO 页里改。

    统计代码自动插入每个页面。
  · 首页可设「扫描+跳转」拦截（PC 端三模式，手机端默认不拦）；
    只拦首页入口，静态内页不拦，不影响收录。
  · 注册 / 资源请求等会员功能页默认 noindex（不抢内页收录权重）。


----------------------------------------------------------------
五、安全与风控（内置）
----------------------------------------------------------------
  · 三层防护：安装路径黑洞 + 敏感目录 / 后缀拦截 + 内部文件反直访。
  · 网页安装器 install.php 带【自锁】：仅在"尚未安装"时可用；装完写入
    config/install.lock 后，它对所有人返回 404（与文件不存在无异），
    没人能借它重装站点或读到服务器信息。提交安装表单还要带会话 CSRF
    令牌，并有蜜罐字段与失败节流。
  · /setup、/upgrade、/update 及 install.php.bak 等安装类路径仍一律 404。
  · 命令行安装器 tools/install-cli.php 公网访问 404，与网页安装器
    共用同一套内核 core/Installer.php（建表 SQL / 生成配置完全一致）。
  · 注册与提交风控：同一 IP 每小时最多注册 3 个 / 登录失败满 5 次
    锁 15 分钟 / 每人每日提交上限（默认 5 条）/ 同 IP 十分钟最多
    15 条 / 同名请求去重 / 蜜罐字段 / 算术验证码（一次有效，30 分钟过期）。
  · 所有写操作带 CSRF 令牌（恒时比较）；表单走 POST→重定向→GET，
    不依赖 JavaScript，避免「点了没反应」。

七、兼容与升级
----------------------------------------------------------------
  · PHP 5.6 ~ 8.2 全兼容。
  · 升级不会覆盖你的设置（后台设置存数据库；发布包不含 config/config.php）。
  · 升级方法：备份数据库与 config → 覆盖上传新包 → 重启 PHP →
    强刷页面 → 打开 check.php 体检。
  · 新增的表会自动创建，缺列会自动补齐，
    【覆盖升级不需要手工执行任何 SQL】。
