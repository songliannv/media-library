================================================================
  媒资资料库（media-library-api）· 安装说明
  版本：v1.6.4          更新：2026-09-23
================================================================

【这份文件是干什么的】
  一步一步教你把本站装到宝塔面板的服务器上，照着做即可，不需要懂编程。
  装好之后想看各功能怎么用，请打开同目录的「功能说明.txt」。


----------------------------------------------------------------
一、服务器要求
----------------------------------------------------------------
  · 面板：宝塔 Linux 面板
  · PHP：5.6 ~ 8.2（推荐 7.4 或 8.0）
  · 数据库：MySQL 5.6+ 或 MariaDB 10.2+
  · 扩展：pdo_mysql、curl、openssl、mbstring（宝塔默认都有）
  · 伪静态：必须配置（见第四步）


----------------------------------------------------------------
二、上传文件
----------------------------------------------------------------
  1) 宝塔 → 网站 → 添加站点
     填你的域名；一并创建数据库，记住「数据库名 / 用户名 / 密码」。

  2) 宝塔 → 文件 → 进入站点根目录（一般是 /www/wwwroot/你的域名/）。

  3) 把本包内【全部文件】上传到站点根目录。
     注意是把包里的文件夹和文件直接放进去，不要再套一层目录。
     传完后站点根应该能看到 index.php、install.php、admin、core、api 等。

  4) 权限：目录 755、文件 644（宝塔默认即可）。


----------------------------------------------------------------
三、设置运行目录与 PHP 版本
----------------------------------------------------------------
  · 宝塔 → 网站 → 设置 → 网站目录 → 运行目录保持为「/」（根目录）。
  · 同一页面的「PHP 版本」选 7.4 或 8.0（5.6 也能跑，但不推荐）。
  · 若开了「防跨站攻击(open_basedir)」，保持默认即可；若后续自检报权限
    FAIL，可在同一位置临时关闭再复查。


----------------------------------------------------------------
四、配置伪静态  ★必做
----------------------------------------------------------------
  不配这一条，后台 /admin、接口 /api/v1/*、资源请求 /request 等
  动态地址会全部 404（但首页仍能打开，容易误判成「没装好」）。

  宝塔 → 网站 → 设置 → 伪静态 → 下拉选「自定义」，把下面整段粘进去并保存：

      location / {
          try_files $uri $uri/ /index.php?$query_string;
      }
      location ^~ /config/   { return 404; }
      location ^~ /sql/      { return 404; }
      location ^~ /core/     { return 404; }
      location ^~ /cron/     { return 404; }
      location ^~ /adapters/ { return 404; }
      location ^~ /tools/    { return 404; }
      location ~* \.(sql|md|lock|bak|ini|log|env|sh|yml|yaml|conf|sample)$ { return 404; }
      location ~* ^/(setup|upgrade|update) { return 404; }

  说明：
  · 第一条是核心：把动态地址交给 index.php 处理；真实存在的静态文件
    和静态内页（/uisc/xxx.html）仍由 Nginx 直接返回，不消耗 PHP。
  · 后面几条是安全保护，防止别人下载你的配置、源码、SQL 与备份文件。
  · 目录保护必须写「^~」，写成普通 location /config/ 会被面板自带的
    .php 正则抢先命中，等于没保护。
  · 安装路径这条【故意不写 install】：网页安装器 install.php 由它自身判定
    （已安装就返回 404），若在 Nginx 层拦死，未安装时就永远装不了了。
  · 不要套用面板里 ThinkPHP / Laravel 的预设伪静态，本项目不是那些框架。


----------------------------------------------------------------
五、安装（网页 / 命令行，二选一）
----------------------------------------------------------------

  【方式一】网页安装（推荐，不用终端）

   1) 浏览器打开：  http://你的域名/install.php
      （也可以先打开首页 http://你的域名/ ，点页面上的
        「🚀 开始网页安装」按钮进入）

   2) 页面会先做环境自检（PHP 版本、扩展、目录权限），
      不通过的项目标红，并直接给出修法。

   3) 填表：数据库地址 / 端口 / 库名 / 用户名 / 密码，
      站点名称与网址，后台管理令牌（留空会自动生成一个 16 位随机串，
      旁边有「生成一个」链接），TMDB / RAWG Key 可留空，
      勾选要启用的数据源。

   4) 点「开始安装」→ 自动建表 → 生成 config/config.php →
      写入安装锁。成功页会给你：后台令牌 / 后台地址 / 自检地址。

   5) 装完再打开 /install.php 就是 404 了 —— 这是【正确现象】：
      安装器已自动锁死，任何人都无法借它重装你的站。

  【方式二】命令行安装（适合重装 / 迁移 / 没有 web 环境）

   宝塔 → 网站 → 设置 → 终端（或用自己的 SSH 工具连服务器），执行：

       cd /www/wwwroot/你的域名
       php tools/install-cli.php

   按提示依次输入：数据库地址（一般 127.0.0.1）、端口、库名、用户名、
   密码、后台令牌（可空，会自动生成）。

   程序会自动完成：检测环境 → 连接数据库 → 建表 → 生成
   config/config.php → 写入安装锁。

  · 两份安装器是【同一套内核】，用哪个装上来的结果都一样。
  · 重装 / 换服务器：命令行加 --force（原 config.php 会自动备份）；
    网页重装则先删掉 config/install.lock 与 config/config.php。
  · 安装信息备忘写在 config/install-info.txt（里面有后台令牌），
    该目录公网访问不到，但记下令牌后仍建议删掉它。

----------------------------------------------------------------
----------------------------------------------------------------
六、装完自检（3 步）
----------------------------------------------------------------
  1) 浏览器打开：  http://你的域名/
     看到主页卡片墙 = 安装成功；
     看到「站点尚未安装」引导页 = 还没装好：页面上那个
     「🚀 开始网页安装」按钮点一下就能装（或回到第五步）。

  2) 浏览器打开：  http://你的域名/check.php?token=你的后台令牌
     共 11 组检查，按提示逐项处理。
     （第一次进后台时会显示后台令牌，也可在后台「系统设置」里修改）

  3) 浏览器打开：  http://你的域名/admin
     输入后台令牌，进入管理后台。


----------------------------------------------------------------
七、装完建议做的 4 件事
----------------------------------------------------------------
  1) 后台 →「系统设置」：填 TMDB / RAWG 的 API Key，开启要用的数据源。
  2) 后台 →「站点设置 → SEO」：填站名 / 关键词 / 描述 / 统计代码，
     并保存 robots.txt、sitemap.xml 内容（页面内有预览按钮）。
  3) 后台 →「站点设置 → 资源请求」：按需开关注册与资源请求页。
  4) 宝塔 →「计划任务」：新增一条 Shell 脚本，周期 1 小时，内容为
         php /www/wwwroot/你的域名/cron/sync_hourly.php
     用于每小时自动采集最新热门内容。
     （后台「同步采集」页有可一键复制的命令）


----------------------------------------------------------------
八、常见问题速查
----------------------------------------------------------------
  Q：打开 /admin 或 /api/v1/* 是 404？
  A：伪静态没配好，回到第四步。检查是否保存成功、是否粘成了别的规则。

  Q：打开 /request 是 404？
  A：同样是伪静态；另外确认站点根目录没有被占用的同名文件或目录。

  Q：访问 /install.php 是 404，是不是装不了？
  A：分两种情况。
     ① 站点【已经装好】了 → 404 是正常的，安装器已自动锁死
        （config/install.lock 存在即对所有人返回 404），与文件不存在
        完全一样；确实要重装就先删掉 config/install.lock 与
        config/config.php。
     ② 站点根目录里【没有】install.php（用的是旧包，或上传时漏了）
        → 从发布包把它传到站点根目录即可，或直接走第五步的命令行安装。

  Q：命令行跑完了，首页还是「站点尚未安装」？
  A：① 确认站点根存在 config/config.php；
     ② 打开看里面 db 段的密码是否还是 CHANGE_ME 占位值；
     ③ 用 check.php 看第 3 组「安装状态」的具体原因。

  Q：登录后一会儿又变回未登录？
  A：PHP 会话目录不可写。宝塔 → 软件商店 → PHP-x.x → 设置 → 配置修改，
     把 session.save_path 指向的目录建好并给 www 用户可写权限。

  Q：界面样式乱了 / 改的设置前台没变化？
  A：先强制刷新（Ctrl+F5）；仍不行就宝塔「清空网站缓存」并重启 PHP。

  Q：https:// 打开是 502 Bad Gateway，http:// 却正常？
  A：说明 Nginx 的 443 那段里 PHP 转发坏了（80 段是好的，所以页面出得来）。
     ① 宝塔 → 网站 → 该站点 → 配置文件：看 listen 443 段里的
        include enable-php-XX.conf; 在不在、版本与「PHP 版本」是否一致；
     ② 宝塔 → 软件商店 → 对应 PHP 版本 → 重启；
     ③ 仍不行看 /www/wwwlogs/你的域名.error.log 最后几行，
        Nginx 会直接写明原因（如 connect() to unix:...sock failed）；
     ④ 也可以把「网站 → 设置 → PHP 版本」重选一次并保存，
        让面板重写站点配置。

  Q：升级新版本会覆盖我填的设置吗？
  A：不会。后台改的设置都存在数据库里，且发布包不含 config/config.php。
     升级方法：先备份 → 覆盖上传新包 → 重启 PHP → 强刷页面 →
     打开 check.php 体检。


----------------------------------------------------------------
九、安全提醒
----------------------------------------------------------------
  · 后台令牌请设复杂一些，不要用 admin / 123456 这类。
  · 网页安装器带自锁：装好后 config/install.lock 存在，它会自动 404；
     不打算用它可以直接删掉站点根的 install.php，不影响任何功能。
  · 不要把 config/config.php 里的数据库信息发给任何人。
  · 定期备份数据库（宝塔 → 计划任务 → 备份数据库）。
  · 任何升级前先备份，出问题可随时回滚。
