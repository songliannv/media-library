================================================================
  媒资资料库（media-library-api）· 功能说明
  版本：v1.6.4          更新：2026-09-23
================================================================

【一句话介绍】
  一套自己搭的「影视 / 游戏 / 动漫」资料库：后台自动采集热门条目 →
  前台卡片墙展示 → 可下载、可筛选、能被搜索引擎收录；
  同时对外提供标准 API，可直接对接 ZBLOK 等 WordPress 资源主题。


----------------------------------------------------------------
一、前台（访客看到的部分）
----------------------------------------------------------------
  1) 主页  /
     · 卡片墙：海报 / 标题 / 评分 / 年份 / 类型
     · 排序切换：热度 / 点击 / 最新 / 评分
     · 分类筛选：短剧 / 电影 / 电视剧 / 动漫 / 综艺 / 游戏
     · 分页浏览；可选「最新更新」区块
     · 前台不出现「API」等字样，访客看到的就是一个正常资源站

  2) 静态内页  /uisc/{id}.html
     · 详情信息 + 按类型差异化展示
       （影视→演职人员、游戏→平台厂商、动漫→话数制作公司、人物→生平）
     · 多条网盘下载：夸克 / 迅雷 / 光鸭 / 百度 / UC（后台可自由增删类型）
     · 只有填了下载地址才显示下载区
     · 真实静态 HTML，收录友好

  3) 注册 / 登录 / 退出  【v1.6.2 新增】
     · /user/register 注册：用户名 2~20 位（支持中文）/ 邮箱选填 /
       密码 6~64 位 / 算术验证码
     · /user/login 登录、/user/logout 退出
     · 密码加盐加密存储；账号不存在时也不会被探测出来

  4) 资源请求  /request  【v1.6.2 新增】
     · 注册用户填写想找的资源：片名 / 类型 / 年份 / 备注 / 联系方式
     · 「我的请求」：查看处理进度、撤回还没处理的提交
     · 「大家都在找」：公开列表（后台可关闭）
     · 提交时自动提示站内是否已收录同名内容

  5) 顶部导航与顶栏
     · 导航项后台勾选（主页 / 榜单 / 分类 / 资源请求 / 自定义外链）
     · 右上角用户区：未登录显示「登录 / 注册」，登录后显示
       「我的请求 / 用户名 / 退出」


----------------------------------------------------------------
二、后台（站长管理，入口 /admin）
----------------------------------------------------------------
  1) 条目管理
     · 按 6 大分类分栏；新增 / 编辑 / 删除条目
     · 每类有专属扩展字段（集数 / 导演 / 地区 / 平台 / 开发商 …）
     · 多条网盘下载地址维护
     · 下载链接失效检查（单条 / 批量）

  2) 系统设置
     · 管理员令牌 / TMDB Key / RAWG Key / 启用数据源 / 网盘类型，
       全部可视化增删改，Key 支持一键「测试连通」
     · 存在数据库，优先级高于 config.php，升级覆盖不丢

  3) 站点设置（v1.6.2 起共 6 个二级页）
     · 基础设置：站名 / 隐藏站名 / 宣传语 / LOGO / icon / 网站网址 /
       页脚三段（图片可直接上传）
     · SEO：标题·关键词·描述三件套 / 统计代码 / 列表页与内页标题模板 /
       内页描述截取字数 / robots.txt / sitemap.xml（均带预览）
     · 扫描+跳转：PC 端「跳转+扫码 / 仅跳转 / 仅扫码」+ 手机端策略 +
       群二维码 + 前端模板 + 顶部导航 + 榜单有图无图 + 最新列表
     · 网盘链接：按网盘分组维护 Cookie / 默认转存目录 / 临时资源目录
     · 接口配置：PanSou 网盘搜索对接 + 测试连接 + 试搜 + 待确认队列
     · 资源请求：13 项开关（开放注册 / 必须登录才能提交 / 注册审核 /
       图形验证 / 游客可看 / 公开列表 / 显示联系方式 / 导航入口 /
       每日上限 / 最少标题字数 / 页面标题 / 页面简介 / 站长公告）

  4) 资源请求  【v1.6.2 新增，一级页签】
     · 请求列表：统计条 + 搜索 + 状态筛选
       （待处理 / 已找到 / 未找到 / 已回复 / 已关闭）
       可标记已找到 / 回复 / 关闭 / 重开 / 删除
     · 注册用户：通过审核 / 禁用 / 解禁 / 重置密码 / 删除
       （删用户只是停用账号，其历史请求仍保留在列表里）

  5) 同步采集
     · 参数：每源条数 / 时间窗 / 口径 / 最低票数 / 重复处理 /
       最小间隔 / 请求上限
     · 只取「最热」与「最多人看」；严格按各源官方要求限流；
       重复条目自动跳过；只为新条目生成静态页
     · 页面内附各源官方限制对照表 + 宝塔计划任务一键复制命令

  6) 安全防护
     · 一眼看清安装器当前状态（未上传 / 已自锁 / 尚未安装因而可用）、
       敏感目录与内部文件守卫是否到位
     · 一键打开带令牌的环境自检报告

  7) 环境自检  /check.php?token=你的后台令牌（或 /check、/health）
     · 共 11 组：① 运行环境 ② 目录权限 ③ 安装状态 ④ 数据库
       ⑤ 表结构 ⑥ 路由伪静态 ⑦ 上游连通 ⑧ PHP 语法 + 安全防护
       ⑨ 采集与计划任务 ⑩ 站点设置·SEO·网盘接口 ⑪ 注册与资源请求
     · 支持 ?format=json 供程序读取；未带正确令牌一律 404


----------------------------------------------------------------
三、对外 API（给别的程序调用）
----------------------------------------------------------------
  1) TMDB 兼容代理  /3/*
     把 ZBLOK 等 WordPress 资源主题的 TMDB base URL 改成你的域名，
     主题零改动即可对接。

  2) 统一 API  /api/v1/*
     列表 / 搜索 / 详情 / 分类 / 计数等，返回 JSON。

  3) 数据源适配器
     TMDB（影视）、RAWG（游戏）、Bangumi（动漫），可按接口继续扩展。


----------------------------------------------------------------
四、自动化与 SEO
----------------------------------------------------------------
  · 静态页：采集入库后自动为新条目生成 /uisc/{id}.html；
    后台可一键全量重建。
  · /robots.txt 与 /sitemap.xml 由路由动态输出，内容在后台 SEO 页里改。
  · 首页 / 列表页 / 内页三种上下文自动套用标题模板；
    统计代码自动插入每个页面。
  · 首页可设「扫描+跳转」拦截（PC 端三模式，手机端默认不拦）；
    只拦首页入口，静态内页不拦，不影响收录。
  · 注册 / 资源请求等会员功能页默认 noindex（不抢内页收录权重）。


----------------------------------------------------------------
五、安全与风控（内置）
----------------------------------------------------------------
  · 三层防护：安装路径黑洞 + 敏感目录 / 后缀拦截 + 内部文件反直访。
  · 网页安装器 install.php 带【自锁】：仅在"尚未安装"时可用；装完写入
    config/install.lock 后，它对所有人返回 404（与文件不存在无异），
    没人能借它重装站点或读到服务器信息。提交安装表单还要带会话 CSRF
    令牌，并有蜜罐字段与失败节流。
  · /setup、/upgrade、/update 及 install.php.bak 等安装类路径仍一律 404。
  · 命令行安装器 tools/install-cli.php 公网访问 404，与网页安装器
    共用同一套内核 core/Installer.php（建表 SQL / 生成配置完全一致）。
  · 注册与提交风控：同一 IP 每小时最多注册 3 个 / 登录失败满 5 次
    锁 15 分钟 / 每人每日提交上限（默认 5 条）/ 同 IP 十分钟最多
    15 条 / 同名请求去重 / 蜜罐字段 / 算术验证码（一次有效，30 分钟过期）。
  · 所有写操作带 CSRF 令牌（恒时比较）；表单走 POST→重定向→GET，
    不依赖 JavaScript，避免「点了没反应」。

六、响应式与主题（v1.6.1 起）
----------------------------------------------------------------
  · 前台与后台同时适配手机 / 平板 / 大屏
    （380 / 560 / 768 / 1024 / 1400 / 1800px 六档断点）
  · 前台明暗模式可「跟随系统」，默认开启；经典 / 简约双模板
    （简约模板含明暗两套配色）
  · 后台可一键切换明暗主题；手机端弹层整屏、表格横滑且首列粘住
  · 支持刘海屏安全区、触屏去粘滞、减少动画、高对比度、打印排版


----------------------------------------------------------------
七、兼容与升级
----------------------------------------------------------------
  · PHP 5.6 ~ 8.2 全兼容。
  · 升级不会覆盖你的设置（后台设置存数据库；发布包不含 config/config.php）。
  · 升级方法：备份数据库与 config → 覆盖上传新包 → 重启 PHP →
    强刷页面 → 打开 check.php 体检。
  · 新增的表会自动创建，缺列会自动补齐，
    【覆盖升级不需要手工执行任何 SQL】。

八、目录速览
----------------------------------------------------------------

  sql/             建表与升级 SQL
  tools/           命令行安装器（与网页安装器共用 core/Installer.php）
